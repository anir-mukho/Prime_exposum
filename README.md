## Exponential sums over primes

This is a visualization of the exponential sum over primes
$$\sum_{p\le N}e^{ip\alpha}$$
where $N$ is a positive integer, sum is over primes $p$ and $\alpha$ varies 
in the interval $[0,2\pi]$. Note that the values of the sum for 
$\alpha=0$ and $2\pi$ are obviously $N$, values at irrational $\alpha$ are of central importance to Number Theory. 
The best known upper bound is $O(N^{4/5}\log^3 N)$ (**Vaughan, 1975**)
and the expected one is 
$O(N^{1/2+\epsilon})$ for any $\epsilon>0$ which is considered a 
*hard question*.
